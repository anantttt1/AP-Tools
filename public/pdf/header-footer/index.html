Frequently asked questions

How do I enter header and footer text?

Use the format Header text | Footer text. Leave either side empty when only one is needed.

Will the header and footer appear on every page?

The tool applies the selected text to every page.

Can I use Hindi or emoji text?

The current embedded standard PDF font has limited character support. Use basic Latin characters for best compatibility.
