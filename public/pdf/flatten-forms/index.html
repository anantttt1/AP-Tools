Frequently asked questions

What does flattening a PDF form do?

It converts supported interactive form fields into page content in the output PDF.

Does it work on every PDF form?

The tool supports forms that the browser PDF library can parse as AcroForm fields. Some XFA or unusual forms may not work.

Is flattening the same as password protection?

No. It does not encrypt the document or provide access control.
