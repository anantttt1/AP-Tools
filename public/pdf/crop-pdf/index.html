How to crop pdf pages online

  1. Open Crop PDF Pages and choose a PDF.
  2. Enter x,y,width,height in PDF points, for example 20,20,550,750.
  3. Run the tool. The rectangle must fit within every page's dimensions.

Frequently asked questions

How are crop values measured?

The values are x, y, width and height in PDF points, where 72 points equal one inch.

Can each page have a different crop area?

The current tool applies one crop rectangle to every page.

Does cropping erase content permanently?

The tool sets the PDF crop box; it is not a secure redaction tool. Do not use it to hide confidential information.
