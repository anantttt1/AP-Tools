How to edit pdf metadata online

  1. Open Edit PDF Metadata and select a PDF.
  2. Enter a JSON object containing one or more supported metadata fields.
  3. Use title, author, subject, creator, producer or keywords.
  4. Run the tool and download the PDF with updated metadata.

Frequently asked questions

Which metadata fields are supported?

The tool supports title, author, subject, keywords, creator and producer.

What input format should I use?

Enter valid JSON, such as {"title":"Annual Report","author":"Alex"}.

Does it edit the visible PDF content?

No. It updates document metadata properties, not the visible page text.
